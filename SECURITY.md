# Security

Tavern Shelf is a local-first application that manages user-provided character card files. Reports involving path traversal, unintended file deletion, source corruption, authentication bypass, or unintended network exposure are especially important.

Please use GitHub's private vulnerability reporting for security-sensitive findings when it is available. If it is unavailable, open a minimal issue without exploit details or private user data so a private reporting channel can be arranged.

Do not attach real character libraries, connector tokens, transfer URLs, database files, or other personal data to public issues. Tavern Shelf releases are currently unsigned; signature or SmartScreen warnings alone are not security vulnerabilities.

Only the latest release is supported with security fixes during the pre-1.0 period.
