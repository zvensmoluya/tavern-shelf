# Tavern Shelf v0.2.0

本次更新让收卡与浏览更加方便：直接粘贴链接导入角色，关联卡以封面叠放展示，并换上新的 Q 版 Shelf Keeper 图标。

## 新功能与改进

- **链接导入**：支持公开 PNG / JSON 附件地址，以及 Chub / CharacterHub、RisuRealm、AICharacterCards 和 Pygmalion 的角色卡地址；兼容部分 SillyTavern 常用简写。下载后复用安全收录与内容去重流程，过期链接或网站拦截会显示错误。
- **关联卡浏览**：同一角色的不同原件仍是独立收藏，可自动建立展示关联。书架默认叠放关联卡，也可逐张展开；详情通过封面缩略图切换原件并查看差异摘要。收藏、备注与原件下载各自独立。
- **新品牌图标**：银发、金色发夹和抱卡姿势的 Q 版 Shelf Keeper，统一用于界面、Windows 应用、快捷方式和托盘；透明背景保留完整人物轮廓。
- **Connector 连接**：可通过 `-connector-origin` 显式允许一个受信任的 HTTPS SillyTavern 页面连接本机 Shelf。

## 修复

- 已能识别为角色卡的文件，即使封面、可选字段或部分内容异常，也会保留原始内容并展示读取提示；无法识别的文件仍留在原处。
- 预设与独立世界书 JSON 支持 UTF-8 BOM，收录时保留原始字节。
- Windows 可执行文件内嵌品牌图标，前端内置资源与最新界面保持同步。

## 范围调整

移除已停止的 Player 原生适配编译器与适配附件传输实验。Shelf 继续负责保存、整理和传输原始资源，以及生成确定性的 Content Manifest；二维码传输提供原始资源。已有实验数据不会在启动时自动删除，但不再读取或发送。

## 升级与下载

1. 升级前可在工具面板下载完整 Library 备份。
2. 从托盘选择「退出」，再运行新版安装包；免安装版用户替换原可执行文件。
3. 继续使用原数据目录。升级后应用会从 Managed Source 补建所需的派生元数据，不改写原始角色卡。

- `TavernShelf-Setup-0.2.0.exe`：Windows x64 当前用户安装包。
- `TavernShelf-0.2.0-Windows-x64-portable.exe`：Windows x64 免安装桌面版。
- `tavern-shelf-server-0.2.0-Windows-x64.zip`：Windows x64 headless 服务端。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

桌面版需要 Windows 10 / 11 x64 和 Microsoft Edge WebView2 Runtime。安装包与程序尚未代码签名。
